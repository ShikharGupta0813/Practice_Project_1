PR Assessment
-------------

Problem Complexity
Level: MEDIUM
Summary: This is a multi-tenant access-control fix that has to infer file ownership from predictable, free-form filenames. It also has to cover two separate download routes and handle prefix collisions between bank names.
Factors:
  - Ownership must be derived from filenames built from free-text bank names, which creates prefix/suffix ambiguity between banks
  - Two independent download routes (xlsxdownload and the generic downloads/(.*) FileController) serve the same folder
  - Path-normalisation concerns (../, ./, //) in the generic file route
  - Generated filenames change for two generators, which affects already-existing files
  - Duplicated controller (Exp) requires identical changes

Fix Quality
Level: GOOD
Summary: The fix closes the leak on both routes with a fail-closed, whole-name match that handles bank-name prefix collisions, and it is placed in one shared helper. Its main weaknesses are that the report allow-list must be maintained by hand and that the edge cases have no automated tests.
Strengths:
  - Shared helper used by all three entry points instead of per-controller copies
  - Whole-filename regex match with preg_quote on the bank prefix, plus refusal of names valid for more than one bank, avoids prefix-collision bypasses
  - FileController scopes the check by realpath() inside the temp folder and checks the same path later used by file_exists()/force_download(), so traversal variants cannot skip it
  - Refused files return 404 just like missing files, so the check does not reveal which files exist
  - Bank-book and zip filenames now carry the bank prefix, which also stops two banks' same-named bank-book files from overwriting each other
Areas for Improvement:
  - Add automated tests for mis_report_belongs_to_bank() covering prefix collisions, the bank-id fallback and Bank_Book/zip patterns
  - The report-name allow-list is separate from the generators; a new generator will be silently refused for bank users unless someone remembers to update the helper (consider deriving names from a shared constant)
  - The four-line bank-name lookup (COMPANY_MASTER select, id fallback, safe name) is copied into four places; a helper such as mis_report_safe_bank_name_for_id() would keep generators and the matcher consistent
